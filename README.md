### 3.1. chapter1.bat: выбор технологии

Ключевые участки:
- **Обнуление баллов** (`set score_... =0`) в начале: при повторном запуске из меню старые значения не мешают.
- **Профиль проекта**: после каждого `choice` номер ответа сохраняется в переменную (`p_budget`, `p_scale`, `p_deadline`, `p_skill`, `p_os`, `p_plugins`, `p_support`). Это и есть числовой профиль проекта.
- **Начисление баллов**: `if "%p_budget%"=="1" set /a "..."` добавляет баллы сразу всем трём кандидатам.
- **Определение победителя**: цепочка `if ... goto`. При равенстве баллов выигрывает более дешёвый вариант (Notepad++, затем Atom, затем Sublime Text), потому что по условию бюджет ограничен.

```bat
@echo off
chcp 65001 >nul
rem ============================================================
rem  chapter1.bat - Модуль 1. Выбор текстового редактора
rem  Вариант 2: Sublime Text / Atom / Notepad++
rem  Контекст: команда из 8 разработчиков, ограниченный бюджет
rem ============================================================

rem --- Шаг 0. Обнуляем баллы. Это важно при повторном запуске из меню ---
set score_sublime=0
set score_atom=0
set score_notepadpp=0
set result1=

cls
echo ========================================================
echo   МОДУЛЬ 1. ВЫБОР ТЕКСТОВОГО РЕДАКТОРА ДЛЯ КОМАНДЫ
echo   Кандидаты: Sublime Text, Atom, Notepad++
echo   Контекст: команда из 8 разработчиков, ограниченный бюджет
echo ========================================================
echo.
echo Ответьте на 7 вопросов о проекте. Нажимайте цифру нужного ответа.
echo.

rem --- Вопрос 1. БЮДЖЕТ -------------------------------------------------
echo Вопрос 1 из 7. Какой бюджет на лицензии ПО для редактора?
echo   1. Бюджета нет, только бесплатное ПО
echo   2. Небольшой, лицензии можно купить не всем
echo   3. Бюджет есть, готовы платить за удобство
choice /c 123 /n /m "Ваш ответ: "
set p_budget=%errorlevel%
rem Баллы идут в порядке: Sublime, Atom, Notepad++
if "%p_budget%"=="1" set /a "score_sublime+=0,  score_atom+=15, score_notepadpp+=15"
if "%p_budget%"=="2" set /a "score_sublime+=8,  score_atom+=10, score_notepadpp+=12"
if "%p_budget%"=="3" set /a "score_sublime+=15, score_atom+=8,  score_notepadpp+=8"
echo.

rem --- Вопрос 2. МАСШТАБ ------------------------------------------------
echo Вопрос 2 из 7. Каков масштаб проекта и размер файлов?
echo   1. Небольшие проекты и скрипты
echo   2. Средний проект, сотни файлов
echo   3. Крупный проект, огромные файлы и логи
choice /c 123 /n /m "Ваш ответ: "
set p_scale=%errorlevel%
if "%p_scale%"=="1" set /a "score_sublime+=8,  score_atom+=10, score_notepadpp+=10"
if "%p_scale%"=="2" set /a "score_sublime+=12, score_atom+=8,  score_notepadpp+=10"
if "%p_scale%"=="3" set /a "score_sublime+=15, score_atom+=0,  score_notepadpp+=8"
echo.

rem --- Вопрос 3. СРОКИ --------------------------------------------------
echo Вопрос 3 из 7. Какие сроки у проекта?
echo   1. Жёсткие, начинаем сразу, без настройки инструментов
echo   2. Умеренные
echo   3. Время есть, можно настроить редактор под себя
choice /c 123 /n /m "Ваш ответ: "
set p_deadline=%errorlevel%
if "%p_deadline%"=="1" set /a "score_sublime+=10, score_atom+=5,  score_notepadpp+=15"
if "%p_deadline%"=="2" set /a "score_sublime+=10, score_atom+=8,  score_notepadpp+=10"
if "%p_deadline%"=="3" set /a "score_sublime+=12, score_atom+=12, score_notepadpp+=6"
echo.

rem --- Вопрос 4. КВАЛИФИКАЦИЯ КОМАНДЫ ----------------------------------
echo Вопрос 4 из 7. Какова квалификация команды?
echo   1. В основном начинающие, нужна простота
echo   2. Смешанная команда
echo   3. Опытные, любят кастомизацию и горячие клавиши
choice /c 123 /n /m "Ваш ответ: "
set p_skill=%errorlevel%
if "%p_skill%"=="1" set /a "score_sublime+=8,  score_atom+=8,  score_notepadpp+=15"
if "%p_skill%"=="2" set /a "score_sublime+=12, score_atom+=10, score_notepadpp+=10"
if "%p_skill%"=="3" set /a "score_sublime+=15, score_atom+=10, score_notepadpp+=5"
echo.

rem --- Вопрос 5. ОПЕРАЦИОННЫЕ СИСТЕМЫ ----------------------------------
echo Вопрос 5 из 7. На каких операционных системах работает команда?
echo   1. Только Windows
echo   2. Windows плюс macOS или Linux
echo   3. В основном macOS или Linux
choice /c 123 /n /m "Ваш ответ: "
set p_os=%errorlevel%
if "%p_os%"=="1" set /a "score_sublime+=10, score_atom+=10, score_notepadpp+=15"
if "%p_os%"=="2" set /a "score_sublime+=15, score_atom+=12, score_notepadpp+=0"
if "%p_os%"=="3" set /a "score_sublime+=15, score_atom+=12, score_notepadpp+=0"
echo.

rem --- Вопрос 6. ПЛАГИНЫ ------------------------------------------------
echo Вопрос 6 из 7. Насколько важны плагины и расширяемость?
echo   1. Достаточно минимума
echo   2. Нужен стандартный набор плагинов
echo   3. Нужна широкая экосистема и гибкая настройка
choice /c 123 /n /m "Ваш ответ: "
set p_plugins=%errorlevel%
if "%p_plugins%"=="1" set /a "score_sublime+=5,  score_atom+=5,  score_notepadpp+=10"
if "%p_plugins%"=="2" set /a "score_sublime+=10, score_atom+=8,  score_notepadpp+=10"
if "%p_plugins%"=="3" set /a "score_sublime+=15, score_atom+=12, score_notepadpp+=6"
echo.

rem --- Вопрос 7. ПОДДЕРЖКА ----------------------------------------------
echo Вопрос 7 из 7. Насколько важна активная поддержка и обновления редактора?
echo   1. Критично: нужны обновления и исправления
echo   2. Не критично
choice /c 12 /n /m "Ваш ответ: "
set p_support=%errorlevel%
if "%p_support%"=="1" set /a "score_sublime+=15, score_atom+=0,  score_notepadpp+=15"
if "%p_support%"=="2" set /a "score_sublime+=5,  score_atom+=10, score_notepadpp+=5"

rem --- Вывод профиля и баллов ---------------------------------------------
echo.
echo ========================================================
echo   РЕЗУЛЬТАТ
echo ========================================================
echo Профиль проекта, числа = номера выбранных ответов:
echo   бюджет=%p_budget%, масштаб=%p_scale%, сроки=%p_deadline%, команда=%p_skill%,
echo   ОС=%p_os%, плагины=%p_plugins%, поддержка=%p_support%
echo.
echo Баллы кандидатов:
echo   Sublime Text : %score_sublime%
echo   Atom         : %score_atom%
echo   Notepad++    : %score_notepadpp%
echo.

rem --- Выбор победителя -----------------------------------------------------
rem Побеждает больший балл. При равенстве приоритет у более дешёвого:
rem сначала Notepad++, затем Atom, затем Sublime Text.
if %score_notepadpp% geq %score_sublime% if %score_notepadpp% geq %score_atom% goto win_npp
if %score_atom% geq %score_sublime% goto win_atom
goto win_sublime

:win_npp
set "result1=Notepad++"
set "comment1=Бесплатный и лёгкий, но работает только в Windows."
goto show_result

:win_atom
set "result1=Atom"
set "comment1=Бесплатный и гибкий, но GitHub прекратил развитие Atom в 2022 году - обновлений нет."
goto show_result

:win_sublime
set "result1=Sublime Text"
set "comment1=Быстрый и удобный, но лицензии платные - заложите бюджет на 8 рабочих мест."

:show_result
echo РЕКОМЕНДАЦИЯ: %result1%
echo %comment1%
echo.
pause
exit /b
```

### 3.2. chapter2.bat: инспекция кода

Ключевые участки:
- **Фрагменты кода** выводятся командами `echo`, каждый с номерами строк, как в IDE.
- **Подпрограмма `:check`** принимает номер правильного ответа, название дефекта и пояснение. Одна и та же логика проверки работает для всех пяти фрагментов, поэтому код не дублируется.
- **Подсчёт очков**: `+10` за верный ответ, `-5` за неверный.
- **Уровень ревьюера** по точности: от 80% Senior, от 50% Middle, иначе Junior. Процент считается целочисленно: `set /a percent=correct*100/total`.
- Все пять типов дефектов из задания встречаются по одному разу.

```bat
@echo off
chcp 65001 >nul
rem ============================================================
rem  chapter2.bat - Модуль 2. Инспекция кода
rem  Вариант 2: код настройки и плагинов текстового редактора
rem ============================================================

rem --- Обнуляем счётчики ---
set correct=0
set total=5
set points=0
set result2=

cls
echo ========================================================
echo   МОДУЛЬ 2. ИНСПЕКЦИЯ КОДА
echo   Фрагменты: код настройки и плагинов текстового редактора
echo ========================================================
echo.
echo В каждом фрагменте спрятан один дефект. Типы дефектов:
echo   1. Неинициализированная переменная
echo   2. Мёртвое присваивание
echo   3. Утечка ресурса
echo   4. Магическое число
echo   5. Отсутствие обработки ошибок
echo За верный ответ +10 очков, за неверный -5.
echo.

echo --------------------------------------------------------
echo Фрагмент 1 из 5 - автосохранение
echo 10: def setup_autosave(editor):
echo 11:     editor.autosave_interval = 30000
echo 12:     editor.autosave_enabled = True
echo 13:     return editor
echo.
call :check 4 "магическое число" "Значение 30000 лучше вынести в константу, например AUTOSAVE_INTERVAL_MS."

echo --------------------------------------------------------
echo Фрагмент 2 из 5 - чтение конфигурации редактора
echo 20: def load_editor_config(path):
echo 21:     try:
echo 22:         f = open(path, "r")
echo 23:         text = f.read()
echo 24:     except OSError:
echo 25:         return {}
echo 26:     return parse_settings(text)
echo.
call :check 3 "утечка ресурса" "Файл открыт, но нигде не закрывается. Нужен with open или f.close."

echo --------------------------------------------------------
echo Фрагмент 3 из 5 - установка плагина
echo 30: def install_plugin(name):
echo 31:     url = REPO_URL + "/" + name + ".zip"
echo 32:     data = download(url)
echo 33:     unpack(data, PLUGINS_DIR)
echo 34:     return True
echo.
call :check 5 "отсутствие обработки ошибок" "Загрузка и распаковка могут упасть, а try/except нет."

echo --------------------------------------------------------
echo Фрагмент 4 из 5 - подсчёт открытых вкладок
echo 40: def count_open_tabs(windows):
echo 41:     for w in windows:
echo 42:         total += len(w.tabs)
echo 43:     return total
echo.
call :check 1 "неинициализированная переменная" "Переменная total используется в строке 42 без начального значения. Нужно total = 0 перед циклом."

echo --------------------------------------------------------
echo Фрагмент 5 из 5 - выбор темы оформления
echo 50: def pick_theme(user):
echo 51:     theme = "light"
echo 52:     theme = user.settings.get("theme", "dark")
echo 53:     return theme
echo.
call :check 2 "мёртвое присваивание" "Значение из строки 51 перезаписывается в строке 52 и нигде не используется."

rem --- Итоговый отчёт ---------------------------------------------------------
echo.
echo ========================================================
echo   ИТОГОВЫЙ ОТЧЁТ РЕВЬЮЕРА
echo ========================================================
set /a percent=correct*100/total
set /a wrong=total-correct
echo Просмотрено фрагментов : %total%
echo Правильных ответов     : %correct%
echo Неправильных ответов   : %wrong%
echo Очков                  : %points%
echo Точность               : %percent%%%
if %percent% geq 80 (
    set "result2=Senior Reviewer"
) else if %percent% geq 50 (
    set "result2=Middle Reviewer"
) else (
    set "result2=Junior Reviewer"
)
echo Уровень ревьюера       : %result2%
echo.
pause
exit /b

rem ============================================================
rem  Подпрограмма :check
rem  %1 - номер правильного ответа
rem  %2 - название дефекта
rem  %3 - пояснение
rem ============================================================
:check
echo Тип дефекта: 1-неинициализированная  2-мёртвое присваивание  3-утечка ресурса
echo              4-магическое число  5-нет обработки ошибок
choice /c 12345 /n /m "Ваш ответ: "
set answer=%errorlevel%
echo.
if "%answer%"=="%~1" (
    echo [+] Верно! Дефект: %~2.
    set /a "correct+=1, points+=10"
) else (
    echo [-] Неверно. Правильный ответ: %~1 - %~2.
    set /a "points-=5"
)
echo     Пояснение: %~3
echo.
exit /b
```

### 3.3. chapter3.bat: метод взвешенной суммы (WSM)

Ключевые участки:
- **Подпрограмма `:askw`** вводит вес и проверяет его командой `findstr`: только целое число без лишних символов.
- **Проверка суммы весов**: если сумма не равна 100, программа сообщает об ошибке и возвращает пользователя к вводу (`goto weights`).
- **Подпрограмма `:rate`** принимает оценку 1-5 одной клавишей через `choice`, поэтому неверное значение ввести невозможно.
- **Формула** `S = W1*X1 + W2*X2 + W3*X3 + W4*X4` считается одной командой `set /a`.
- **Матрица решений** выравнивается пробелами; веса дополняются слева пробелами (`%pw1:~-3%`), чтобы колонки не «ехали».
- **Победитель**: берётся максимум; если лидеров несколько, программа объявляет ничью.

```bat
@echo off
chcp 65001 >nul
rem ============================================================
rem  chapter3.bat - Модуль 3. Сравнительный анализ методом WSM
rem  Вариант 2: Sublime Text / Atom / Notepad++
rem  Формула: S = W1*X1 + W2*X2 + W3*X3 + W4*X4
rem ============================================================

set result3=

cls
echo ========================================================
echo   МОДУЛЬ 3. СРАВНИТЕЛЬНЫЙ АНАЛИЗ МЕТОДОМ ВЗВЕШЕННОЙ СУММЫ
echo   Альтернативы: Sublime Text, Atom, Notepad++
echo ========================================================
echo.
echo Критерии сравнения:
echo   1. Скорость работы
echo   2. Плагины и расширяемость
echo   3. Стоимость владения, где 5 = бесплатно, а 1 = дорого
echo   4. Простота освоения

rem --- Шаг 1. Веса критериев с проверкой суммы = 100 ------------------------
:weights
echo.
echo ШАГ 1. Назначьте веса критериям: целые числа, сумма должна быть 100.
call :askw w1 "Вес критерия 1, Скорость работы"
call :askw w2 "Вес критерия 2, Плагины и расширяемость"
call :askw w3 "Вес критерия 3, Стоимость владения"
call :askw w4 "Вес критерия 4, Простота освоения"
set /a total_weight=w1+w2+w3+w4
if %total_weight% neq 100 (
    echo.
    echo ОШИБКА: сумма весов равна %total_weight%, а должна быть 100. Введите веса заново.
    goto weights
)
echo Сумма весов равна 100. Продолжаем.

rem --- Шаг 2. Оценки альтернатив по шкале 1-5 -------------------------------
echo.
echo ШАГ 2. Оцените каждый редактор по шкале от 1 до 5.
echo        1 - очень плохо, 5 - отлично. Для стоимости: 5 = бесплатно.
echo.
echo --- Критерий 1: Скорость работы ---
call :rate s_1 "Sublime Text"
call :rate a_1 "Atom"
call :rate n_1 "Notepad++"
echo.
echo --- Критерий 2: Плагины и расширяемость ---
call :rate s_2 "Sublime Text"
call :rate a_2 "Atom"
call :rate n_2 "Notepad++"
echo.
echo --- Критерий 3: Стоимость владения, 5 = бесплатно ---
call :rate s_3 "Sublime Text"
call :rate a_3 "Atom"
call :rate n_3 "Notepad++"
echo.
echo --- Критерий 4: Простота освоения ---
call :rate s_4 "Sublime Text"
call :rate a_4 "Atom"
call :rate n_4 "Notepad++"

rem --- Шаг 3. Расчёт S = сумма W*X ------------------------------------------
set /a score_s=s_1*w1+s_2*w2+s_3*w3+s_4*w4
set /a score_a=a_1*w1+a_2*w2+a_3*w3+a_4*w4
set /a score_n=n_1*w1+n_2*w2+n_3*w3+n_4*w4
rem Максимум возможен при оценках 5 по всем критериям: 5*100 = 500
set /a pct_s=score_s*100/500
set /a pct_a=score_a*100/500
set /a pct_n=score_n*100/500

rem --- Выравнивание весов по правому краю: добавляем пробелы слева -----------
set "pw1=  %w1%"
set "pw2=  %w2%"
set "pw3=  %w3%"
set "pw4=  %w4%"

rem --- Матрица решений ------------------------------------------------------
echo.
echo ========================================================
echo   МАТРИЦА РЕШЕНИЙ
echo ========================================================
echo Критерий                      Вес  Sublime  Atom  Notepad++
echo -----------------------------------------------------------
echo Скорость работы               %pw1:~-3%        %s_1%     %a_1%          %n_1%
echo Плагины и расширяемость       %pw2:~-3%        %s_2%     %a_2%          %n_2%
echo Стоимость, 5 = бесплатно      %pw3:~-3%        %s_3%     %a_3%          %n_3%
echo Простота освоения             %pw4:~-3%        %s_4%     %a_4%          %n_4%
echo -----------------------------------------------------------
echo ИТОГО S = сумма W*X           %total_weight%      %score_s%   %score_a%        %score_n%
echo.
echo Sublime Text : %score_s% из 500, это %pct_s%%%
echo Atom         : %score_a% из 500, это %pct_a%%%
echo Notepad++    : %score_n% из 500, это %pct_n%%%
echo.

rem --- Определяем победителя; при равенстве перечисляем всех лидеров -----------
set best=%score_s%
if %score_a% gtr %best% set best=%score_a%
if %score_n% gtr %best% set best=%score_n%

set count=0
set "result3="
if %score_s% equ %best% set "result3=Sublime Text"
if %score_s% equ %best% set /a count+=1
if %score_a% equ %best% if defined result3 (set "result3=%result3% и Atom") else set "result3=Atom"
if %score_a% equ %best% set /a count+=1
if %score_n% equ %best% if defined result3 (set "result3=%result3% и Notepad++") else set "result3=Notepad++"
if %score_n% equ %best% set /a count+=1

echo ПОБЕДИТЕЛЬ: %result3%
if %count% gtr 1 echo Внимание: у лидеров одинаковое число баллов, это ничья.
echo.
pause
exit /b

rem ============================================================
rem  Подпрограмма :askw - ввод веса с проверкой
rem  %1 - имя переменной, %2 - подпись
rem  Принимаются только числа 0, 1-9, 10-99, 100-999 без ведущих нулей
rem ============================================================
:askw
set "tmp_w="
set /p "tmp_w=%~2: "
echo %tmp_w%|findstr /r /x "[0-9] [1-9][0-9] [1-9][0-9][0-9]" >nul
if errorlevel 1 (
    echo   Ошибка: введите целое число от 0 до 100.
    goto askw
)
set /a %~1=%tmp_w%
exit /b

rem ============================================================
rem  Подпрограмма :rate - оценка от 1 до 5 одной клавишей
rem  %1 - имя переменной, %2 - название редактора
rem ============================================================
:rate
choice /c 12345 /n /m "   %~2, оценка 1-5: "
set /a %~1=%errorlevel%
exit /b
```

### 3.4. lab_system.bat: главное меню и интеграция

Ключевые участки:
- **`cd /d "%~dp0"`**: переход в папку файла, чтобы `call` и `report.txt` работали при любом способе запуска.
- **Проверка наличия модулей** циклом `for`.
- **Меню на `choice`**: пункт выбирается одной клавишей, `errorlevel` сразу сохраняется в `menu_item`.
- **`call chapterN.bat`** запускает модули. Переменные `result1`, `result2`, `result3` остаются в памяти и доступны главному файлу.
- **Подпрограмма `:report`** выводит итоговый отчёт на экран и записывает его в `report.txt`.

```bat
@echo off
chcp 65001 >nul
rem ============================================================
rem  lab_system.bat - главный файл, объединяет три модуля
rem  Вариант 2: выбор текстового редактора для команды
rem ============================================================

rem Переходим в папку, где лежит сам файл. Тогда call и report.txt
rem работают одинаково при двойном клике, из ярлыка и из консоли.
cd /d "%~dp0"

rem --- Проверяем, что все модули на месте -------------------------------------
for %%f in (chapter1.bat chapter2.bat chapter3.bat) do (
    if not exist "%%f" (
        echo Не найден файл %%f. Положите все .bat файлы в одну папку.
        pause
        exit /b 1
    )
)

:menu
cls
echo ========================================================
echo   СИСТЕМА МОДЕЛИРОВАНИЯ ПРОЦЕССОВ РАЗРАБОТКИ ПО
echo   Вариант 2: выбор текстового редактора для команды
echo ========================================================
echo.
echo   1. Модуль выбора технологий
echo   2. Модуль инспекции кода
echo   3. Модуль сравнительного анализа
echo   4. Запустить все модули последовательно
echo   5. Выход
echo.
choice /c 12345 /n /m "Ваш выбор: "
rem Сразу сохраняем результат choice: errorlevel изменится после любой команды
set menu_item=%errorlevel%

if "%menu_item%"=="1" call chapter1.bat
if "%menu_item%"=="2" call chapter2.bat
if "%menu_item%"=="3" call chapter3.bat
if "%menu_item%"=="4" goto run_all
if "%menu_item%"=="5" goto end
goto menu

:run_all
rem Переменные result1, result2, result3 остаются в памяти после call,
rem потому что модули выполняются в том же окне cmd.
set result1=
set result2=
set result3=
call chapter1.bat
call chapter2.bat
call chapter3.bat
cls
call :report
pause
goto menu

:end
exit /b

rem ============================================================
rem  Подпрограмма :report - итоговый отчёт на экран и в report.txt
rem ============================================================
:report
if "%result1%"=="%result3%" (
    set "verdict=Модули 1 и 3 указывают на один и тот же редактор - выбор хорошо обоснован."
) else (
    set "verdict=Модули 1 и 3 дали разные результаты - стоит обсудить критерии с командой."
)
(
    echo ========================================================
    echo   ИТОГОВЫЙ ОТЧЁТ СИСТЕМЫ
    echo   Вариант 2: выбор текстового редактора для команды
    echo ========================================================
    echo Дата и время: %date% %time:~0,8%
    echo.
    echo Модуль 1. Рекомендация по технологии : %result1%
    echo    Баллы - Sublime Text: %score_sublime%, Atom: %score_atom%, Notepad++: %score_notepadpp%
    echo Модуль 2. Уровень ревьюера           : %result2%
    echo    Верных ответов: %correct% из %total%, точность %percent%%%
    echo Модуль 3. Победитель анализа WSM     : %result3%
    echo    Итоги S - Sublime Text: %score_s%, Atom: %score_a%, Notepad++: %score_n%
    echo.
    echo Вывод: %verdict%
) > report.txt
type report.txt
echo.
echo Отчёт сохранён в файл: %~dp0report.txt
exit /b
```

## 7. Что получилось при запуске интегрированной системы

### 7.1. Диалоги и вопросы

- **Модуль 1** задаёт 7 вопросов: бюджет, масштаб проекта, сроки, квалификация команды, операционные системы, важность плагинов, важность поддержки. Ответы превращаются в числовой профиль проекта и баллы трёх кандидатов.
- **Модуль 2** показывает 5 фрагментов Python-кода (автосохранение, чтение конфигурации, установка плагина, подсчёт вкладок, выбор темы). В каждом нужно определить тип дефекта из списка.
- **Модуль 3** просит назначить веса четырём критериям (сумма 100), затем оценить три редактора по каждому критерию от 1 до 5.

| 2 | 4, 3, 5, 1, 1 | 4 из 5, точность 80%, 35 очков. **Senior Reviewer** |
| 3 | веса 35, 25, 25, 15 | S: Sublime 410, Atom 365, Notepad++ 415. Победитель: **Notepad++** |

### 7.4. Впечатления

Работа помогла увидеть, что выбор инструмента можно формализовать: ответы превращаются в баллы, баллы в рекомендацию. Сложнее всего было с командой choice и errorlevel, который нужно сразу сохранять в переменную, и со специальными символами в echo. Понравилось, что три независимых модуля через call обмениваются данными и собираются в единый отчёт. Метод взвешенной суммы показал, что результат зависит от весов, то есть оценка остаётся субъективной, но становится прозрачной.

## 8. Инструкция по запуску

1. Скачайте репозиторий (кнопка **Code → Download ZIP**) и распакуйте архив.
2. Убедитесь, что `chapter1.bat`, `chapter2.bat`, `chapter3.bat` и `lab_system.bat` лежат **в одной папке**.
3. Запустите двойным кликом `lab_system.bat`. Отдельные модули тоже можно запускать двойным кликом.
4. Выбирайте пункты меню нажатием цифры (без Enter). Веса в модуле 3 вводятся цифрами с Enter.
5. Пункт **4** проходит все модули подряд и создаёт `report.txt` рядом с файлами.

Требования: Windows 10 или 11. Если вместо русских букв видны «кракозябры», откройте каждый `.bat` в Notepad++, выберите **Кодировки → Кодировка → Кириллица → OEM 866**, сохраните и замените в файле строку `chcp 65001 >nul` на `chcp 866 >nul`.
